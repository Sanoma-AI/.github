# Security Policy

Sanoma connectors touch money and employee data, so we take reports seriously.

## Reporting a vulnerability

Do not open a public issue for security problems.

Report vulnerabilities privately through GitHub's private vulnerability reporting: open the affected repository's **Security** tab and choose **Report a vulnerability**.
