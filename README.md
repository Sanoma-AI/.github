# .github

Organization-wide community health files for [Sanoma-AI](https://github.com/Sanoma-AI). GitHub uses these as defaults for every repo in the org that does not define its own.

- [CONTRIBUTING.md](CONTRIBUTING.md): how to contribute, DCO and CLA terms
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md): Contributor Covenant 2.1
- [SECURITY.md](SECURITY.md): how to report vulnerabilities
- [TRADEMARKS.md](TRADEMARKS.md): rules for using the Sanoma name
- [profile/README.md](profile/README.md): the org profile page

## Visibility

Public. No license file; these are policy documents for the org.
